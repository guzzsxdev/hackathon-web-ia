# MedLembra – Lembrete de Medicamentos Assistivo

Projeto do Hackathon Web com IA. Aplicação web (HTML, CSS e JavaScript puro) que lembra o usuário de tomar seus medicamentos, com foco em acessibilidade.

**Autores:** Gustavo Mateus Santana Ferreira e Miguel Lucas Mendes do Monte

## Funcionalidades
- Cadastro de medicamentos (nome, dose e horário) e lista ordenada por horário
- Marcar como tomado, desfazer, excluir e contador de progresso
- Alerta na hora da dose com som e leitura em voz alta, com opção de adiar 5 minutos
- Acessibilidade: letras ajustáveis, alto contraste e voz ligável
- Dados salvos no navegador (localStorage)

## Como rodar
Abra `index.html` no navegador (ou use o Live Server no VS Code).
